# Estilo <nome>

Uma frase que define o estilo (o que alguém sente ao ver).

## Regras de ouro
- (3 a 7 regras curtas e medidas, ex.: "nada leva mais de 6 quadros para chegar", "texto sempre centralizado, uma linha")

## Sistema de movimento
- Curvas: chegada, troca, saida (estilo.json). Onde cada uma é usada.
- Tempos: entrada, saída, escada entre elementos, duração típica de plano.
- Câmera: aproximação, socos, rastreio.
- Transições entre planos: quais existem e o quadro do corte.
- Borrão: obturador medido.

## Tipografia
- Papel → família → peso → tamanho em % da altura → como entra.

## Cor
- Papel de cada cor (estilo.json: COR.fundo, COR.texto, COR.destaque...).

## Componentes (o que já existe em src/pecas)
- Id da peça → o que faz → quando usar → props.

## Som
- Trilha: gênero, BPM, onde comprar ou gerar.
- Efeitos: evento → som (sfx.json) → quantos quadros antes do visual → volume.

## 3D, filmagem e ilustração
- O que o estilo usa e como foi resolvido na recriação (Blender, IA ou motion tradicional).
